# SoloMap Design System 1.3

2026-11-23 · 모바일 전용 화면 + 빨강 포인트 + 혼밥 레벨 캐릭터 · HTML/CSS/JavaScript

## 원칙

모바일 화면 하나를 기준으로 설계한다. PC에서도 가운데 430px 폭으로 같은 화면을 보여 준다(바깥은 흰 바탕, 앱 영역은 얇은 선으로 구분). 흰 바탕에 빨강은 소제목·레벨 미터·다녀왔어요에만 쓴다. 화면을 소개 문구나 큰 계정 패널로 채우지 않는다. 로그인·학교 인증·리뷰·체크인·성장 지도는 기존 API를 사용한다.

- `public/design-system.css`: 공통 토큰과 컴포넌트의 기준.
- `public/style.css`: 화면별 배치. `public/map.css`: 지도 전용 배치.
- `public/ui.js`: 공통 SVG와 모달 키보드 동작.
- `/design-system.html`: 서비스와 같은 CSS를 쓰는 컴포넌트 미리보기.

## 시각적 위계

| 역할 | 표현 | 적용 예 |
|---|---|---|
| 주요 작업 | 진한 중립 채움 + 흰 글자 | 식당 찾기, 인증 완료, 리뷰 저장 |
| 보조 작업 | 회색 채움, 테두리 없음 | 체크인, 지도 링크, 랜덤 추천 |
| 이동·안내 | 투명 배경 + 텍스트 | 로그인, 내 성장 기록, 레벨 안내 |
| 메뉴 | 텍스트, 선택 항목만 옅은 빨강 + 빨간 테두리 | 추천 메뉴 |
| 필터 | 텍스트, 선택 항목만 진한 중립 배경 | 난이도 필터 |
| 보기 전환 | 회색 그룹 안에 선택 항목만 흰색 + 진한 하단선 | 목록 / 지도 |
| 난이도 안내 | 구분선과 작은 레벨 배지 | 상단 5단계 범례 |
| 식당 정보 | 흰 카드 + 얇은 경계 | 검색 결과 |

입력 경계와 포커스는 유지한다. 메뉴·보조 버튼·범례에 모두 같은 외곽 테두리를 두르지 않는다. 점무늬·강한 그림자·큰 안내 배너를 추가하지 않는다. 단계색은 난이도와 의미 있는 피드백에만 사용한다.

## 공통 클래스

```html
<button class="sm-button sm-button--primary">주요 작업</button>
<button class="sm-button">보조 작업</button>
<button class="sm-button sm-button--ghost">텍스트 작업</button>
<button class="sm-button sm-button--danger">삭제</button>
<input class="sm-input" aria-label="입력 항목">
```

주요 작업에만 primary를 쓴다. 기본 `sm-button`은 회색 보조 버튼, `sm-button--ghost`는 텍스트 버튼이다. 실제 `disabled`와 `aria-busy`로 상태를 전달한다. 입력에는 라벨을 연결한다. 아이콘 전용 버튼은 `sm-button--icon`과 `aria-label`을 사용한다.

반복 표면은 `sm-card`, 짧은 상태는 `sm-badge`, 안내는 `sm-notice`, 진행률은 `sm-progress`를 사용한다. 화면별로 색·높이·폰트를 다시 정의하지 않는다. 카드 안에 의미 없는 카드를 중첩하지 않는다.

## 화면과 접근성

- 성장 안내는 작은 기록 스트립으로 유지하고 상세 정보는 내 성장 기록 모달에서 보여준다.
- 모바일에서는 검색 폼을 세로로 배치한다. 컨트롤이나 문구가 가로로 잘리지 않게 한다.
- 포커스 링, 모달 Tab 순환·Escape·포커스 복원, 모션 감소를 유지한다.
- 모달이나 설명에서 기존 기능을 재소개하는 큰 섹션을 추가하지 않는다.

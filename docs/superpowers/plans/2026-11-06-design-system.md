# SoloMap 디자인 시스템 적용 계획

**목표:** 재사용 가능한 토큰·컴포넌트와 PC/모바일 레이아웃을 만들고 실제 화면에 적용한다.
**범위:** 기존 HTML/CSS/JS 유지. 백엔드/데이터 규칙은 변경하지 않는다. 사용자가 지정한 ui-ux-pro-max 스킬을 설치·읽고 디자인/검수 검색에 사용한다.

## 구조
- `public/design-system.css`: 컬러·타입·간격·크기·레이어·모션 토큰, 버튼/필드/배지/표면/포커스 공통 컴포넌트.
- `public/ui.js`: 공통 SVG 아이콘, 모달 키보드 접근성 등 반복 UI 동작.
- `public/style.css`: 앱 레이아웃/식당/성장 화면. 중복 선언을 정리하고 지도 스타일은 별도 `map.css`로 보존한다.
- `public/design-system.html`: 실제 CSS를 공유하는 컴포넌트 미리보기.
- `design-system/solomap/MASTER.md`: 토큰의 의미·적용 규칙과 컴포넌트 사용법.
- `docs/DESIGN_SYSTEM_AUDIT.md`: 스킬 검색 결과의 적합성 판단, 측정 기반 검수 결과와 한계.

## 실행
- [x] 반응형/터치 타깃/대비/키보드/컴포넌트 재사용 테스트를 먼저 추가하고 실패 확인.
- [x] Pretendard 기반 12/14/16/20/24/32/40 타입, 4px 간격, 의미 기반 컬러·레벨 토큰 정의.
- [x] 사용자 선택에 따라 딥블루 브랜드/액션과 쿨 뉴트럴 사용. 기존 로고 자산 유지, 난이도 의미 색은 분리.
- [x] 버튼·필드·배지·카드·탭·모달을 공통 클래스로 연결하고 지도 엔진 스타일 분리.
- [x] 375/768/1024/1440, 모바일 가로, 200% 텍스트 확대, reduced-motion, 모달 포커스 검증.
- [x] 실제 화면과 컴포넌트 갤러리의 렌더링·기존 계정/검색/지도 회귀 확인.
- [x] ui-ux-pro-max 기준 검수 및 독립 코드 리뷰. 최종 typecheck/build, Express 16/16, 운영 11/11 및 정적 파일 HTTP 200 확인.

## 스킬 적용 판단
`restaurant discovery warm minimal --design-system`은 미니멀 그리드/가벼운 효과 방향이 맞지만 레스토랑 랜딩용 패턴과 영문 Playfair/Karla는 한글 식당 탐색 도구에 맞지 않는다. 해당 폰트/빨강 팔레트를 그대로 저장하지 않고 Pretendard와 사용자가 선택한 딥블루·뉴트럴로 제품에 맞춘다. 터치 간격/타입 위계/키보드 포커스는 ux 도메인 검색 결과를 적용한다. Tailwind가 없는 프로젝트이므로 html-tailwind 구현 권고는 적용하지 않는다.

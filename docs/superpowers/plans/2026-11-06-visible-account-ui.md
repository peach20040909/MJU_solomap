# 로그인·성장 기능 화면 반영

사용자가 로그인/새 기능을 화면에 반영해 달라고 요청했다. 기존 Express·HTML/CSS/JS 및 서버 API를 사용하며 로그인 우회나 가짜 개인 기록은 만들지 않는다. .agents/rules/autonomous.md에 따라 중간 승인 없이 기존 요구 범위를 직접 실행한다.

- [x] 기존 브라우저 회귀 테스트에 분리된 로그인/회원가입, 첫 화면 기능 진입점, 성장 안내, 로그인 상태의 실제 진행률, 설정 미완료 안내를 추가하고 실패를 확인한다.
- [x] index.html/style.css: 헤더 계정 버튼, 성장 영역, 세 가지 새 기능 안내와 이용 흐름 모달. 기존 검색/지도를 유지한다.
- [x] account.js: 버튼 연결, 서버 프로필로 성장 영역 갱신, 로그아웃 초기화. 서버 config의 accountConfigured로 미준비 상태 안내.
- [x] app.ts의 공개 config는 비밀값 없이 계정 설정 여부 boolean만 제공한다. DB 연결 건강 상태라고 주장하지 않는다.
- [x] 실제 3000 서버 실행, 자동 브라우저 회귀 통과. 사용자 Chrome은 URL 확인 제한으로 열기 중단; 실제 시각 검토는 미완료.

환경: 기존 3001은 다른 앱. SoloMap 서버는 3000으로 실행. 사용자는 별도 SoloMap Supabase 프로젝트를 사용할 예정이며 실제 DB·SMTP는 아직 미설정.

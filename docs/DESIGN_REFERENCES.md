# SoloMap 레퍼런스와 목업 방향

2026-11-09. 기능 구현을 유지하고 목업으로 방향을 먼저 비교한다. 이 작업 중 운영 배포는 중단했다.

| 실제 확인한 서비스 | 확인한 화면 | SoloMap에 적용할 패턴 | 가져오지 않을 요소 |
|---|---|---|---|
| [네이버 지도](https://map.naver.com/) | 명지대 혼밥 검색 결과 | 검색·결과 패널과 지도 분리, 식당명·거리 우선 | 광고와 부가 내비게이션 |
| [카카오맵](https://map.kakao.com/) | 명지대 혼밥 검색 결과 | 얇은 구분선, 짧은 메타 정보, 목록과 핀 대응 | 모든 지도 도구를 한 줄에 노출하는 구조 |
| [캐치테이블](https://app.catchtable.co.kr/) | 혼밥맛집 진입 후 지도/목록 | 모바일 지도 위 하단 시트, 선택 필터 강조 | 예약 인원·날짜·가격 등 SoloMap에 없는 기능, 광고 팝업 |
| [다이닝코드](https://www.diningcode.com/) | 명지대 혼밥 맛집 검색 | 식당명 → 핵심 특성 → 리뷰 요약의 순서 | 긴 태그 목록, 광고, 제공되지 않는 식당 사진 |
| [Google 지도](https://www.google.com/maps) | 명지대 식당 검색 | 작은 검색 컨트롤과 계정 영역, 지도와 결과 분리 | 대형 홍보 헤더 |

## 비교할 목업

- A: 목록 중심. 기존 사용자 흐름을 유지하되 짧은 검색 영역과 읽기 쉬운 카드로 정돈.
- B: 지도 중심. PC는 검색/결과 패널 + 큰 지도, 모바일은 지도 + 식당 상세 시트.
- 공통: 계정은 한 메뉴, 식당명 우선, 난이도는 작은 라벨, 리뷰/체크인 명확한 행동, 주소·전화·외부 지도는 상세에서 제공.
- 실제 제공되지 않는 사진·별점·영업 상태·가격을 추가하지 않는다. 지도 배경은 목업용 벡터 예시이며 실제 지도 정확성을 나타내지 않는다.

## 로컬 구현 보존

운영 반영 전 사용자 피드백으로 목업 단계로 전환했다. 그 전에 작업한 헤더 계정 disclosure, 카드 위계, 두 지도 엔진 공통 팝업은 로컬에만 있으며 기존 UI/기능 회귀 테스트가 통과했다. 운영은 이전 DS1.2 배포 상태를 유지한다.
